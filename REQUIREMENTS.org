* Core
** hyprland
Should resolve /most/ of its dependencies and optionals automatically. If not, see the installation guide.
**  xdg-desktop-portal-hyprland
If not installed by hyprland proper.
** grimblast
For screenshots.
** qt6ct-kde
For theming QT apps. Note: patched AUR version!
** nwg-look
For theming GKT apps.
** kitty
The go-to terminal for Hyprland.
** Dolphin
Graphical file browser.
** Babashka
For scripts.

* Noctalia
Noctalia itself handles the bulk of the interface here.
See the [[https://docs.noctalia.dev/v4/][official Noctalia installation guide]] for more information.
Here are some of the key dependencies.
** quickshell
To install Noctalia at all – it's the runtime.
** Matugen
Material color scheme generator. Necessary for theming.
** wlsunset
Color temperature control.
** ddcutil
Brightness control.
** cliphist
Clipboard history
** Cava
Audio visualisation.
